# Python_Number_Guessing_Game
A short program written in python that runs in the terminal. It generates a random number which then prompts the user to enter a guess as to what the number is. This was created to showcase the knowledge I obtained in Introduction to Programming. This was not created for an assignment submission.

Input prompts the user to enter their guess and int makes sure that the value is an integer. The while loop keeps the program running until the user has guessed correctly. Within the loop if/elif/else give the user an output either directing them closer to the answer or informing them that they answered correctly.
